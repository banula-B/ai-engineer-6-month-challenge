# 📚 Why Learn Linear Algebra?

Linear Algebra is the language of Machine Learning.

Almost every Machine Learning algorithm works with vectors and matrices internally.

Examples:

- Dataset → Matrix
- Images → Matrix of pixel values
- Neural Network Weights → Matrices
- Word Embeddings → Vectors

Although libraries like **NumPy** perform these operations with a single function call, understanding the mathematics behind them will make advanced AI topics much easier to learn.

---

# 🔹 What is a Vector?

A **vector** is an ordered collection of numbers.

Example:

```python
v = [2, 5, 7]
```

This vector has **3 dimensions**.

A vector can represent:

- A point in space
- A direction
- A collection of features

Example:

```text
Age = 22
Height = 175
Weight = 70

↓

[22, 175, 70]
```

This is called a **feature vector**.

---

# 🔹 What is a Matrix?

A **matrix** is a rectangular arrangement of numbers.

Example:

```text
|1 2 3|
|4 5 6|
|7 8 9|
```

Python representation:

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```

A matrix consists of:

- Rows
- Columns

Example above:

- 3 Rows
- 3 Columns

---

# 🔹 Matrix Dimensions

Matrix dimensions are written as:

```text
Rows × Columns
```

Example:

```text
2 × 3

|1 2 3|
|4 5 6|
```

Another example:

```text
3 × 2

|1 2|
|3 4|
|5 6|
```

Understanding dimensions is important because not every pair of matrices can be multiplied.

---

# 🔹 Dot Product

The **dot product** combines two vectors into a single number.

Example:

```text
A = [1, 2, 3]
B = [4, 5, 6]
```

Multiply corresponding elements:

```text
1 × 4 = 4
2 × 5 = 10
3 × 6 = 18
```

Add the results:

```text
4 + 10 + 18 = 32
```

Therefore:

```text
Dot Product = 32
```

Using NumPy:

```python
import numpy as np

A = np.array([1,2,3])
B = np.array([4,5,6])

print(np.dot(A, B))
```

Today, focus on understanding **how** this calculation works rather than simply using NumPy.

---

# 🔹 Matrix Multiplication

Matrix multiplication is **not** element-wise multiplication.

Each value in the output matrix is calculated by taking the **dot product** of a row from Matrix A and a column from Matrix B.

Example:

```text
Matrix A

|1 2|
|3 4|

Matrix B

|5 6|
|7 8|
```

First element:

```text
(1 × 5) + (2 × 7)

=

5 + 14

=

19
```

This process is repeated for every position in the result matrix.

---

# 🔹 Rules for Matrix Multiplication

Two matrices can only be multiplied if:

```text
Columns of Matrix A
        =
Rows of Matrix B
```

Valid example:

```text
2 × 3

×

3 × 4

✓ Valid
```

Result:

```text
2 × 4
```

Invalid example:

```text
2 × 3

×

2 × 2

✗ Invalid
```

# 💻 Practical Task

## Implement Matrix Multiplication from Scratch

Do **not** use:

```python
np.matmul(A, B)
```

or

```python
A @ B
```

Instead, implement the algorithm yourself using **nested loops**.

### Suggested Steps

1. Check if the matrices can be multiplied.
2. Create an empty result matrix filled with zeros.
3. Loop through each row of Matrix A.
4. Loop through each column of Matrix B.
5. Calculate each element using row-by-column multiplication.
6. Store the value in the result matrix.
7. Print the final matrix.

---

# 🤖 Why This Matters for AI

Every neural network performs matrix multiplication during the forward pass.

```text
Input Features
       ↓
Weight Matrix
       ↓
Matrix Multiplication
       ↓
Activation Function
       ↓
Output
```

Understanding matrix multiplication will make it much easier to learn how neural networks work.
