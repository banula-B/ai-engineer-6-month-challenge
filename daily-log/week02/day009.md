# 📚 Why Learn Eigenvalues & Eigenvectors?

Many Machine Learning algorithms work with high-dimensional data.

Examples include:

- Images with thousands of pixels
- Text embeddings
- Sensor measurements
- Financial datasets

Working with high-dimensional data can:

- Slow down training
- Increase memory usage
- Introduce noise
- Cause overfitting

To solve this problem, Machine Learning often uses **Principal Component Analysis (PCA)**, which is built upon Eigenvalues and Eigenvectors.

---

# 🔹 What is a Linear Transformation?

A **linear transformation** changes vectors while preserving the structure of the space.

Examples include:

- Scaling
- Rotation
- Reflection
- Shearing

Matrices are commonly used to represent these transformations.

Example:

```
Matrix
   ↓
Transforms
   ↓
Vector
```

Most vectors change both **length** and **direction** after a transformation.

However...

---

# 🔹 What is an Eigenvector?

An **Eigenvector** is a special vector whose **direction remains unchanged** after a linear transformation.

Only its length changes.

Example:

```
Before Transformation

      ↑
      |
      |
      ●

↓

After Transformation

          ↑
          |
          |
          |
          |
          ●
```

The vector points in the **same direction**, but it becomes longer (or shorter).

---

# 🔹 What is an Eigenvalue?

The **Eigenvalue** tells us **how much** the Eigenvector changes in length.

If:

```
Eigenvalue = 3
```

The vector becomes **3 times longer**.

If:

```
Eigenvalue = 0.5
```

The vector becomes **half its original length**.

If:

```
Eigenvalue = -1
```

The vector flips direction.

---

# 🔹 Mathematical Definition

If

```
A
```

is a matrix,

```
v
```

is an Eigenvector,

and

```
λ
```

is an Eigenvalue,

then:

```
Av = λv
```

Meaning:

Applying the transformation **A** to vector **v** produces the same vector multiplied by **λ**.

---

# 🔹 The Characteristic Equation

To find Eigenvalues we solve:

```
det(A - λI) = 0
```

Where:

- **A** = Matrix
- **I** = Identity Matrix
- **λ** = Eigenvalue
- **det()** = Determinant

Once the Eigenvalues are known, we can calculate the corresponding Eigenvectors.

You do not need to manually solve these equations today—focus on understanding the concept.

---

# 🔹 Visual Intuition

Imagine stretching a rubber sheet.

Most arrows drawn on the sheet rotate and stretch.

However,

a few arrows continue pointing in exactly the same direction.

Those arrows are the **Eigenvectors**.

The amount they stretch is their **Eigenvalue**.

---

# 🔹 Why Are They Important?

Eigenvalues and Eigenvectors help us discover:

- Important patterns
- Hidden directions in data
- Maximum variance
- Data compression opportunities

This is exactly what PCA uses.

---

# 📊 What is PCA?

**Principal Component Analysis (PCA)** is one of the most popular dimensionality reduction techniques.

Its goal is to reduce the number of features while keeping as much information as possible.

Example:

Original dataset

```
Age
Salary
Height
Weight
Experience
Education
```

↓

After PCA

```
PC1
PC2
```

Instead of six features, we now have only two principal components that retain most of the important information.

---

# 🔹 Why PCA?

Benefits:

- Faster model training
- Less memory usage
- Removes redundant information
- Reduces noise
- Helps visualize high-dimensional datasets
- Can improve model performance

---

# 🔹 How PCA Works

Step 1

Standardize the data.

↓

Step 2

Calculate the covariance matrix.

↓

Step 3

Find Eigenvalues and Eigenvectors.

↓

Step 4

Sort Eigenvalues from largest to smallest.

↓

Step 5

Select the top Eigenvectors.

↓

Step 6

Project the data onto the new feature space.

---

# 🔹 Principal Components

The Eigenvector with the **largest Eigenvalue** becomes:

```
Principal Component 1 (PC1)
```

It captures the greatest amount of variance.

The second largest Eigenvalue becomes:

```
Principal Component 2 (PC2)
```

And so on.

---

# 💡 Key Idea

The larger the Eigenvalue,

the more important that Eigenvector is.

Large Eigenvalue

↓

More Information

↓

More Useful Feature

---

# 💻 PCA Example Using Scikit-learn

```python
from sklearn.decomposition import PCA
from sklearn.datasets import load_iris

data = load_iris()

X = data.data

pca = PCA(n_components=2)

X_new = pca.fit_transform(X)

print(X_new.shape)
```

Output:

```
(150, 2)
```

The original dataset has **4 features**.

After PCA:

Only **2 features** remain.

---

# 📈 Explained Variance

To see how much information is retained:

```python
print(pca.explained_variance_ratio_)
```

Example output:

```
[0.92, 0.05]
```

Meaning:

- PC1 explains 92% of the variance.
- PC2 explains 5%.

Together:

97% of the original information is preserved.
