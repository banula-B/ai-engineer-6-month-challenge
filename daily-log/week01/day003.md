# 2. Pandas Series

A **Series** is a one-dimensional labeled array that can store different types of data.

## Creating a Series

```python
data = [12, 33, 54, 21, 47]

series = pd.Series(data)

print(series)
```

---

## Custom Index

By default, Pandas assigns numeric indexes starting from `0`.

We can also create our own indexes.

```python
series = pd.Series(
    data,
    index=["a", "b", "c", "d", "e"]
)

print(series)
```

---

## Accessing Data with `.loc`

The `.loc[]` property accesses data using the **index label**.

```python
print(series.loc["a"])
```

---

## Updating Values

We can change values using `.loc`.

```python
series.loc["c"] = 200

print(series)
```

---

## Accessing by Position with `.iloc`

Even after assigning custom indexes, we can still access values using their position.

```python
print(series.iloc[2])
```

---

## Filtering a Series

We can retrieve values that satisfy a condition.

```python
series[series < 30]

series[series > 20]

series[series == 12]
```

---

## Adding New Values

A new element can be added by assigning a new index.

```python
series["f"] = 40

print(series)
```

---

## Creating a Series from a Dictionary

```python
calories = {
    "day1": 420,
    "day2": 380,
    "day3": 390
}

series = pd.Series(calories)
```

Selecting only specific keys:

```python
series = pd.Series(
    calories,
    index=["day1"]
)
```

# 3. Pandas DataFrame

A **DataFrame** is a two-dimensional table consisting of rows and columns.

## Creating a DataFrame

```python
data = {
    "calories": [420, 380, 390],
    "duration": [50, 40, 45]
}

df = pd.DataFrame(data)

print(df)
```

---

## Custom Row Index

```python
df = pd.DataFrame(
    data,
    index=["day1", "day2", "day3"]
)

print(df)
```

---

## Accessing Rows with `.loc`

```python
print(df.loc["day1"])
```

---

## Accessing Rows with `.iloc`

```python
print(df.iloc[2])
```

---

# 4. Adding Data to a DataFrame

## Adding a New Column

```python
df["Activity"] = [
    "Jogging",
    "Running",
    "Running"
]
```

---

## Adding a New Row

```python
new_row = pd.DataFrame(
    [{
        "calories": 400,
        "duration": 45,
        "Activity": "Jogging"
    }],
    index=["day4"]
)

df = pd.concat([df, new_row])
```

---

## Adding Multiple Rows

```python
new_rows = pd.DataFrame([
    {
        "calories": 380,
        "duration": 20,
        "Activity": "Swimming"
    },
    {
        "calories": 250,
        "duration": 30,
        "Activity": "Walking"
    },
    {
        "calories": 350,
        "duration": 45,
        "Activity": "Cycling"
    }
], index=["day5", "day6", "day7"])

df = pd.concat([df, new_rows])
```

# 5. Importing Data

## Reading a CSV File

```python
df = pd.read_csv("../data sets/pokemon.csv")

print(df)
```

### Printing the Entire Dataset

```python
print(df.to_string())
```

> **⚠️ Note:** Avoid printing very large datasets with `to_string()` because it may freeze your program or consume a large amount of memory.

---

## Reading a JSON File

```python
df = pd.read_json("../data sets/pokemon.json")

print(df)
```

---

# 6. Selecting Data

## Selecting a Single Column

```python
df["Name"]
```

---

## Selecting Multiple Columns

```python
df[["Name", "Type1"]]
```

---

## Setting a Column as the Index

```python
df = pd.read_csv(
    "../data sets/pokemon.csv",
    index_col="Name"
)
```

Now each Pokémon name becomes the row index.

---

## Selecting a Row by Label

```python
df.loc["Pikachu"]
```

---

## Selecting Specific Columns from a Row

```python
df.loc[
    "Pikachu",
    ["Type1", "Legendary"]
]
```

---

## Selecting Multiple Rows

```python
df.loc[
    "Charizard":"Blastoise",
    ["Type1", "Height"]
]
```

---

## Selecting Rows and Columns by Position

```python
df.iloc[
    0:11,
    1:3
]
```
