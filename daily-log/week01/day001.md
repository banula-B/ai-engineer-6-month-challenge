# 📚 Topics Covered

## 1. Creating NumPy Arrays

Learned how to create different types of arrays:

- 1D Arrays
- 2D Arrays
- 3D Arrays

```python
import numpy as np

a = np.array([1, 2, 3])

b = np.array([
    [7, 6, 5],
    [5, 4, 3]
])
```

---

## 2. Understanding Array Properties

Learned how to inspect arrays using built-in attributes.

| Property | Description |
|----------|-------------|
| `.ndim` | Returns the number of dimensions |
| `.shape` | Returns the shape of the array |
| `.dtype` | Returns the data type of array elements |

Example:

```python
print(a.ndim)
print(a.shape)
print(a.dtype)
```

## 6. Creating Special Arrays

Learned useful NumPy functions for generating arrays.

### Zero Matrix

```python
np.zeros((2, 4, 3))
```

### Ones Matrix

```python
np.ones((4, 3, 2))
```

### Matrix Filled with a Specific Number

```python
np.full((2, 3), 23)
```

### Using `full_like()`

```python
np.full_like(b, 12)
```

### Random Decimal Numbers

```python
np.random.rand(4, 2)
```

### Random Integers

```python
np.random.randint(7, size=(4, 3))
```

### Identity Matrix

```python
np.identity(5)
```

### Repeating Arrays

```python
arr = np.array([[3, 4, 5, 6]])

np.repeat(arr, 5, axis=0)
```

## 8. Copying Arrays

Discovered the difference between assigning an array and copying an array.

### Assignment

```python
b = a
```

Both variables reference the **same memory location**.

### Correct Copy

```python
b = a.copy()
```

Now both arrays are independent.

## 9. Mathematical Operations

Performed arithmetic directly on NumPy arrays.

Examples:

```python
a + 2
a - 2

```

Performed element-wise operations between two arrays.

## 10. Array Slicing

Learned how to extract portions of an array.

### Row Slicing

```python
array[0:3]
```

### Column Slicing

```python
array[:, 1]
```

### Row and Column Slicing

```python
array[0:2, 0:2]
```

### Negative Indexing

```python
array[-2:, -2:]
```

---

## 11. Broadcasting

Learned one of NumPy's most powerful features.

### Adding a Number to Every Element

```python
arr + 4
```

### Adding Two Arrays

```python
arr1 + arr2
```

### Broadcasting Between Different Dimensions

```python
row_array + column_array
```

Learned that broadcasting works only when array shapes are compatible.

# 💡 Key Learnings

- NumPy arrays are significantly faster than Python lists.
- Arrays have dimensions and shapes that define their structure.
- Indexing and slicing allow efficient data access.
- Broadcasting enables mathematical operations without loops.
- `.copy()` creates an independent copy of an array.
- NumPy provides many built-in methods for generating different kinds of arrays.
