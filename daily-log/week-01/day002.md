## 1. Broadcasting

Broadcasting is a NumPy feature that allows arithmetic operations between arrays with different shapes when their dimensions are compatible.

For example:

```python
array1 = np.array([[1, 2, 3, 4]])
array2 = np.array([[1], [2], [3], [4]])

print(array1 * array2)
```

Although the two arrays have different shapes, NumPy can broadcast them to perform the multiplication.

### Main Broadcasting Rules

### Rule 1 — Compare Dimensions from Right to Left

When comparing two array shapes, start from the rightmost dimension and move toward the left.

For example:

```text
A = (3, 4)
B = (4,)
```

The dimensions are aligned as:

```text
A = (3, 4)
B = (   4)
```

The `4` dimensions match, so broadcasting is possible.

---

### Rule 2 — Equal Dimensions Are Compatible

Two corresponding dimensions are compatible when they have the same size.

Examples:

```text
3 vs 3 → Compatible
4 vs 4 → Compatible
5 vs 5 → Compatible
```

---

### Rule 3 — A Dimension of 1 Can Be Broadcast

A dimension is also compatible when one of the corresponding dimensions is `1`.

Examples:

```text
3 vs 1 → Compatible
4 vs 1 → Compatible
1 vs 5 → Compatible
```

For example:

```text
A = (3, 4)
B = (3, 1)
```

Compare from right to left:

```text
4 vs 1 → Compatible
3 vs 3 → Compatible
```

Therefore, broadcasting is possible.

---

## When Broadcasting Fails

Broadcasting fails when corresponding dimensions are different and neither dimension is `1`.

Example:

```text
A = (3, 4)
B = (3, 2)
```

Comparing from right to left:

```text
4 vs 2 → Not compatible
```

Therefore, these arrays cannot be broadcast together.

### Key Idea

When checking whether two arrays can work together:

1. Start from the right.
2. Compare corresponding dimensions.
3. They must either:

   * be equal, or
   * one of them must be `1`.

# 2. Aggregate Functions

Aggregate functions summarize data and often return a single value.

Today I practiced several NumPy aggregate functions.

### `np.sum()`

Calculates the sum of values.

```python
np.sum(array)
```

### `np.mean()`

Calculates the average.

```python
np.mean(array)
```

### `np.std()`

Calculates the standard deviation.

```python
np.std(array)
```

### `np.var()`

Calculates the variance.

```python
np.var(array)
```

### `np.min()`

Finds the minimum value.

```python
np.min(array)
```

### `np.max()`

Finds the maximum value.

```python
np.max(array)
```

### `np.argmin()`

Returns the index of the minimum value.

```python
np.argmin(array)
```

### `np.argmax()`

Returns the index of the maximum value.

```python
np.argmax(array)
```

---

# 3. The `axis` Parameter

Aggregate functions can also be applied along a specific axis.

For example:

```python
np.sum(array, axis=0)
```

performs the calculation column-wise.

While:

```python
np.sum(array, axis=1)
```

performs the calculation row-wise.

### Important Understanding

For a 2D array:

```text
axis=0 → work down the rows → result for each column

axis=1 → work across the columns → result for each row
```

This concept will become very important when working with datasets.

# 4. Filtering NumPy Arrays

NumPy arrays can be filtered using conditions.

Example:

```python
ages[ages < 65]
```

This selects the values that satisfy the condition.

Multiple conditions can also be combined.

Example:

```python
ages[(ages > 18) & (ages < 50)]
```

This selects values that are:

```text
greater than 18
AND
less than 50
```

### Important Operators

```text
&  → AND
|  → OR
~  → NOT
```

When using multiple conditions with NumPy, each condition should be enclosed in parentheses.

---

# 5. `np.where()`

`np.where()` can be used to select values based on a condition.

The basic idea is:

```python
np.where(condition, value_if_true, value_if_false)
```

For example:

```python
adults = np.where(ages >= 18, ages, 0)
```

This means:

```text
If age >= 18:
    use the original age

Otherwise:
    use 0
```

This is useful for transforming data based on conditions.

# 6. Random Number Generation

NumPy provides tools for generating random numbers.

I learned how to create a random number generator using:

```python
rng = np.random.default_rng()
```

This creates a NumPy random number generator.

---

## Generating Random Integers

To generate a random integer between `1` and `6`:

```python
rng.integers(1, 7)
```

The upper limit is exclusive, so this can produce:

```text
1, 2, 3, 4, 5, 6
```

This is useful for simulating things such as dice rolls.

---

# 7. Generating Multiple Random Numbers

The `size` parameter can be used to generate multiple random values.

Example:

```python
rng.integers(low=1, high=101, size=3)
```

This generates three random integers from `1` through `100`.

---

# 8. Generating Random Matrices

The `size` parameter can also specify the shape of the generated array.

Example:

```python
rng.integers(low=1, high=101, size=(3, 2))
```

This generates a:

```text
3 × 2
```

matrix containing random integers.

This is useful for creating test data and simulations.

---

# 9. Shuffling Arrays

NumPy can randomly rearrange the elements of an array using:

```python
rng.shuffle(array)
```

For example:

```python
array = np.array([1, 2, 3, 4, 5])

rng.shuffle(array)
```

The values remain the same, but their order changes.

---

# 10. Random Choice

The `choice()` method can randomly select an element from an array.

Example:

```python
fruits = np.array([
    "apple",
    "orange",
    "banana",
    "pineapple",
    "grapes"
])

fruit = rng.choice(fruits)
```

This randomly selects one fruit from the array.

---

# 11. Random Seeds

Random number generation normally produces different values each time.

A seed can be used when reproducible results are required.

Example:

```python
rng = np.random.default_rng(seed=1)
```

Using the same seed allows the same sequence of random numbers to be generated again.

This is particularly useful in Machine Learning because experiments often need to be reproducible.
